# Публикация YouTube-выжимок · py.motomov.ru

## Склад

| Файл | Раздел | kind | id |
|---|---|---|---|
| `data/youtube.json` | YouTube (`youtube.html`) — **свежая лента** | всегда `"youtube"` | `yt-<videoId>` |
| `data/youtube-archive.json` | Архив старых выжимок (тот же формат) | `"youtube"` | `yt-<videoId>` |

Детальная страница: `brief.html?id=yt-…&kind=youtube`. Логика `loadBrief` в `js/app.js` подгружает `youtube.json`, когда `kind=youtube` или `id` начинается с `yt-`.

**Все сводки сохраняем.** Ничего не удаляем «чтобы освободить место»: при росте ленты старые записи переезжают в архив, а не выкидываются.

## Архив (когда лента разрастётся)

Порог: когда в `data/youtube.json` станет **больше ~40** записей — перенести самые старые в `data/youtube-archive.json` (массив, тот же формат полей).

Правила переноса:
1. На ленте (`youtube.json`) остаются свежие (порядка последних ~40).
2. В архив уходят более старые; порядок внутри архива — как удобно (обычно newest-first или oldest-first, но без дыр в id).
3. Перед переносом: прочитать оба файла → убедиться, что `id` не дублируется → записать оба JSON.
4. Полноценная страница архива YouTube (по образцу `archive.html` для novosti) — когда записей станет много; пока достаточно склада `youtube-archive.json`.

## Железные правила

1. **ВСЕГДА prepend** новой записи в начало `youtube.json`.
2. **НИКОГДА** не truncate / replace всего файла одной записью.
3. Не трогать `briefs.json`, `novosti.json`, `kb.json` и прочие склады других агентов.
4. Перед записью: прочитать JSON → если `id` уже есть, **обновить на месте**, иначе `[new, ...items]`.
5. Проверка: `python -c "import json; d=json.load(open('data/youtube.json')); print(len(d), d[0]['id'])"`.

## Поля записи

`id`, `kind`, `date`, `dateLabel`, `channel`, `channelHandle`, `videoId`, `url`, `topic`, `title`, `summary`, `body` (массив строк/блоков как у briefs).

## Обязательный блок · Оценка Motomov

В **каждом** `body` должен быть блок с заголовком `## Оценка Motomov` (обычно перед `## Для кого` / `## Ссылка`).

Содержание — честная субъективная аналитика, не пересказ ролика:
- **Польза** — что реально можно взять в работу.
- **Хайп** — где заголовок/цифры раздуты или опираются только на слова автора/вендора.
- **Слабые места** — спонсорство, узкий сетап, нет субтитров, устаревающие бенчи и т.п.
- **Можно ли опираться** — на что да / что перепроверить самому.

Без этого блока обзор не считается готовым.

## Чеклист одного обзора

1. Взять свежий ролик канала (`yt-dlp --playlist-end 1`).
2. Опереться на субтитры или title+description; не выдумывать фактов. Если субтитров нет — явно написать об этом и опираться на описание/таймкоды.
3. Собрать русскую выжимку.
   - Обычный обзор / гайд / дайджест: о чём / 5–8 тезисов (или блоки) / для кого / ссылка.
   - **Поучительные / длинные интервью** (как Владилен Минин): развёрнутый сюжет — ход разговора, мысли и посыл гостя/ведущего, почти-цитаты только из субтитров; `summary` на карточке короткий (1–3 предложения), `body` — как статья.
4. Добавить блок `## Оценка Motomov` (см. выше).
5. Prepend в `data/youtube.json` (или update на месте при том же `id`).
6. Commit + push `main`.
