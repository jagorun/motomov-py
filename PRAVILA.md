# Правила правок py.motomov.ru

## Урок 05 — живой чертёж сайта

Файл: `data/lessons.json`, объект с `"id": "05-site"`.
Живая страница: https://py.motomov.ru/lesson.html?id=05-site

При любом изменении сайта в том же коммите дописать этот урок:

- что изменилось на экране;
- какой файл и какой id/функция за это отвечают;
- обновить «Дату этой карты» в первом блоке урока.

Правка меню, редиректа, имён разделов, `app.js`, складов JSON, выкладки Vercel без абзаца в уроке 05 считается незакрытой.

Это правило для человека и для Grok.

## Что не забывать вместе с уроком

- Меню копируется во все HTML-оболочки. Меняешь один пункт — меняешь все страницы шапки.
- Корень `/` настраивается в `vercel.json`, не в `index.html`.
- Две ленты сводок — два файла. Ссылка на сводку: `brief.html?id=...&kind=...`.
- После пуша в `main` проверить живой URL, не только превью.
